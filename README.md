## 📌 Project Overview
An AI-powered application designed to analyze text inputs and accurately detect the underlying emotional state (such as joy, anger, sadness, or fear). This project is built as part of the IBM Generative AI Engineering certification.

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **Frameworks:** Transformers / Pipeline API
* **Deployment:** Jupyter Notebook / GitHub

## 🚀 Getting Started
1. Clone this repository to your local environment.
2. Install the required dependencies from the project requirements file.
3. Run the notebook to analyze text strings for emotion classification.
